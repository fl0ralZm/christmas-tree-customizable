# 圣诞树（可定制） 🎄

一个可以输入名字、选择颜色、上传照片，并生成独立分享网页的互动圣诞树生成器。基于照片墙重制版整理。

## 功能

- 自定义收件人名字、树的颜色和祝福语。
- 导入最多 30 张照片，形成可展开的照片墙。
- 照片不足五张时，用英文祝福卡片补足。
- 粒子圣诞树、飘雪、入场动画，以及鼠标和触屏交互。
- 可选摄像头手势控制：旋转、聚拢、散开和查看照片。
- 下载包含所选照片的独立 HTML 文件，或复制生成的网页代码。

## 如何使用

1. 下载本仓库，打开 `index.html`，进入生成器。
2. 输入名字，设置颜色和祝福语。
3. 在预览区域导入照片，或使用默认祝福卡片。
4. 下载生成的 HTML 文件并分享。接收者用现代浏览器打开即可。

**分享的 HTML 会包含你选择的照片与填写的文字。请只分享你愿意公开的内容。** 本仓库默认姓名为空，没有附带个人照片。

建议使用近期版本的 Chrome、Edge 或 Safari。摄像头受浏览器权限及安全上下文限制；若直接打开文件时无法启用手势，请使用 HTTPS 页面或下面的本地预览。

## 本地预览与修改

需要 Node.js 18 或更高版本，无需安装 npm 依赖。

```sh
npm start
```

打开终端显示的本机地址，默认 `http://127.0.0.1:8765`。

```text
index.html                完整生成器入口，包含离线资源
src/editor.js             名字、颜色、预览和分享导出逻辑
src/scene-engine.js       粒子场景、照片墙与手势逻辑
src/scene-style.css       场景样式及内嵌字体
src/scene-markup.html     场景界面
src/gesture-worker.js     手势识别 Worker
THIRD_PARTY_NOTICES.txt   第三方来源与许可原文
```

编辑 `src/` 后运行：

```sh
npm run build
npm run check
```

构建会把源码重新嵌入 `index.html`，保留其中已经内嵌的模型、WASM 等资源。无需另行下载模型或配置 API 密钥。

## 已知限制

- 手势会受光照、遮挡、设备性能影响；握拳与双指捏合之间仍可能误判。也可以用鼠标或触屏交互。
- 内嵌模型和运行时使入口文件约为 20 MB；首次加载、保存大量照片可能较慢。
- 页面运行和导出效果取决于浏览器；手势识别需要允许访问摄像头。
